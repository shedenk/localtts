Method Endpoint Keterangan & Parameter Utama
GET /v1/models Daftar engine yang siap dipakai (kokoro, edge, omnivoice, qwen3, whisper).
POST /v1/audio/speech TTS JSON: model, input, voice, language (en-us/id), response_format (mp3/wav/opus/flac), speed.
POST /v1/audio/transcriptions Whisper STT multipart: file, model (tiny/base/small/medium/large-v3-turbo), language (id/en), response_format (json/text/srt/verbose_json).
GET /health Healthcheck server (tanpa auth, untuk Docker/Coolify).
